# Secure Academic Certificate Storage and Verification System

## Project Overview

The Secure Academic Certificate Storage and Verification System is a web-based platform designed to securely store and verify academic certificates using SHA-256 hashing and blockchain-based record linking.

The system helps prevent certificate tampering and provides a reliable method for verifying certificate authenticity through QR-based verification.

## Objective

To build a secure platform for academic certificate storage and verification using SHA-256 hashing, database integration, QR verification, and blockchain technology.

## How It Works

Admin Login → Certificate Upload → Hash Generation → Blockchain Record → Database Storage → QR Verification → Integrity Check

## Key Features

- Secure academic certificate storage
- SHA-256 hash generation
- Blockchain-based record linking
- QR code-based certificate verification
- Certificate tamper detection
- Database integration
- Integrity checking
- Admin dashboard

## System Workflow

1. Admin logs into the system.
2. Certificate is uploaded.
3. SHA-256 hash is generated for the certificate.
4. Certificate record is linked to the blockchain.
5. Certificate details are stored in the database.
6. QR code is generated for verification.
7. User scans the QR code.
8. Certificate authenticity is verified.
9. Hash integrity is checked to detect tampering.
